# Polaris Portal

Create a visually rich, responsive polar science portal using advanced glassmorphism and dynamic dark/light theme toggles for drastic aesthetic shifts. Design a sticky navigation bar with a logo, site-wide links, and a login button. The login flow should open a stylish overlay. Once authenticated, display seven interactive, role-selection cards: Student, Teacher, Scientist, Researcher, Science Communicator, Policy Maker, and Other.

For the content experience, build an Instagram-style auto-playing media feed, a 3D interactive globe widget for precise coordinate searching, and a real-time data dashboard. Finally, create a dedicated Media Dissemination page centered on a floating, glassmorphic AI chat widget. To integrate the chatbot, paste your AI platform's embed code into the Insert menu's Embed component on that specific page.
